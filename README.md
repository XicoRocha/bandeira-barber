## Sobre o código

Em setembro de 2026, **antes do arranque formal do projeto** (2 de novembro de 2026), foi feito um protótipo exploratório.
Para que o `main` corresponda à fase em que o projeto está (planeamento, Sprint 1), o código está guardado à parte:

- branch [`prototipo-v0`](https://github.com/XicoRocha/bandeira-barber/tree/prototipo-v0) e etiqueta `v0-prototipo-exploratorio` (commits de 25 e 28 de setembro de 2026);
- o histórico do `main` mantém esses commits, por isso nada foi apagado.

O protótipo não é a especificação do produto. Os requisitos são definidos nas entregas E5 e E6 a partir do Product Owner,
o protótipo é comparado com eles e volta ao `main` revisto como **Documento 22 (Wireframes ou protótipo)**, na E7.
Ver [`docs/prototipo/`](docs/prototipo/README.md).
